# PostgreSQL migrations

Схема применяется командой `npm run db:migrate`. Runner читает файлы в
лексикографическом порядке, создаёт таблицу `schema_migrations` и записывает
версию только после успешного применения миграции. Повторный запуск уже
применённые версии пропускает.

Текущая нумерованная миграция создаёт:

- товары и варианты;
- категории и SEO-поля;
- цены и остатки;
- checkpoint и журнал синхронизации МойСклад;
- корзины и заявки покупателей;
- независимые email-уведомления менеджеру и покупателю по одному заказу.

Миграции применяются отдельной командой до запуска новой версии приложения.
Новые изменения добавляются отдельными файлами `002_*.sql`, `003_*.sql` и т.д.
Секреты и реальные данные в репозиторий не добавляются.

`009_catalog_characteristic_filters.sql` добавляет управляемые фильтры по
характеристикам и списки значений «Применение» и «Отрасль».

`010_reviews.sql` добавляет статус заказа «Оплачен», одноразовые приглашения
оставить отзыв, модерацию отзывов и новые типы email-уведомлений.

`011_catalog_admin_consistency.sql` задаёт единый порядок категорий для
админки и витрины и нормализует регистр названий характеристик по справочнику.
